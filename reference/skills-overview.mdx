ASO Skills is an open-source library of 20+ specialist AI agent skills for App Store Optimization and mobile app marketing. Each skill encodes battle-tested frameworks, scoring rubrics, and output templates so your AI agent — whether that's Cursor, Claude Code, or any Agent Skills-compatible tool — gives you expert-level guidance instead of generic advice. Connect the Appeeky MCP Server to pull live App Store data into every skill automatically.

## How to Invoke a Skill

You can invoke skills in two ways: use the **`/aso-skill` router** to describe your goal in plain language and let the router pick the right specialist, or call a skill directly by name when you know which one you want.

<Tabs>
  <Tab title="Router (Recommended)">
    Use `/aso-skill` followed by any natural-language request. The router reads your intent and hands off to the right specialist skill automatically.

    ```
    /aso-skill  Run an ASO audit for my app (id: 1617391485)
    /aso-skill  Find the best keywords for a meditation app targeting the US
    /aso-skill  What apps are rising in the Health & Fitness charts right now?
    ```
  </Tab>
  <Tab title="Direct Invocation">
    Call any skill by its slash command when you know exactly what you need.

    ```
    /aso-audit
    /keyword-research
    /metadata-optimization
    /competitor-analysis
    /market-movers
    /market-pulse
    /app-marketing-context
    /asc-metrics
    ```
  </Tab>
</Tabs>

<Tip>
  Run `/app-marketing-context` first, before any other skill. It creates a shared `app-marketing-context.md` file that every other skill reads automatically — so you never have to repeat your app name, audience, competitors, or goals.
</Tip>

## The `/aso-skill` Router

The router is a single entry point for the entire library. Instead of remembering 30 skill names, you describe what you want and the router determines the best specialist skill to invoke.

```
/aso-skill  Why isn't my app ranking for "habit tracker"?
/aso-skill  Help me plan a Christmas In-App Event
/aso-skill  My app rating dropped from 4.7 to 4.2 — how do I recover?
/aso-skill  What seasonal keywords should I add in December?
/aso-skill  Build an Apple Search Ads campaign structure for my fitness app
```

<Note>
  The router works best after you've run `/app-marketing-context`. With your app's context loaded, the router can make smarter routing decisions and pass relevant context to the specialist skill it invokes.
</Note>

## How Skills Work Together

Skills are designed to chain — the output of one feeds naturally into the next.

```
/app-marketing-context   →  Saves app context once
       ↓
/aso-audit               →  Scores your listing, finds weak spots
       ↓
/keyword-research        →  Discovers high-opportunity keywords
       ↓
/metadata-optimization   →  Writes new title, subtitle, keyword field
       ↓
/ab-test-store-listing   →  Designs and interprets A/B tests
```

<Tip>
  Skills reference each other in their output. For example, `/aso-audit` will suggest `/keyword-research` for keyword gaps it finds, and `/keyword-research` will suggest `/metadata-optimization` when you're ready to implement.
</Tip>
