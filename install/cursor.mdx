Cursor loads skills from local directories (`.cursor/skills/`, `~/.cursor/skills/`, and `.agents/skills/`). Install with the Agent Skills CLI, or clone the repository and copy the `skills/` folder yourself. Both methods give your Cursor agent the same expert ASO frameworks.

## Method 1: Skills CLI (Recommended)

The CLI copies every skill into Cursor's skills directories so the agent can invoke them by name.

<Steps>
  <Step title="Open a terminal in your project">
    Run the command from the project where you want the skills available (project-level), or from anywhere if you plan to install globally.
  </Step>
  <Step title="Install the skills">
    **Project-level** (this repo only — commit `.cursor/skills/` or `.agents/skills/` so teammates get them):

    ```bash
    npx skills add eronred/aso-skills -a cursor
    ```

    **Global** (every Cursor project on this machine):

    ```bash
    npx skills add eronred/aso-skills -a cursor -g
    ```
  </Step>
  <Step title="Start a new Agent chat">
    Cursor reads skill metadata when a chat starts. Open a new Agent conversation after installing.
  </Step>
</Steps>

<Tip>
  Type `/` in chat and look for `/aso-router` (or any specialist like `/aso-audit`) to confirm the skills loaded.
</Tip>

## Method 2: Manual Clone and Copy

Use this method when you want to pin a specific version of the skills, modify them locally, or skip the CLI.

<Steps>
  <Step title="Clone the repository">
    Open your terminal and run:

    ```bash
    git clone https://github.com/eronred/aso-skills.git
    ```
  </Step>
  <Step title="Copy skills to your Cursor skills directory">
    For a **project-level** install (only available in the current project):

    ```bash
    mkdir -p .cursor/skills
    cp -r aso-skills/skills/* .cursor/skills/
    ```

    For a **global** install (available in all Cursor projects):

    ```bash
    mkdir -p ~/.cursor/skills
    cp -r aso-skills/skills/* ~/.cursor/skills/
    ```
  </Step>
</Steps>

## Verify the Installation

Once installed, open a new Cursor chat window and try invoking a skill. The quickest check is the router skill, which accepts any natural-language ASO request:

```text
/aso-router  Run an ASO audit for my app
```

Or invoke a skill directly by name:

```text
/aso-audit
```

```text
/keyword-research
```

If the agent responds with a structured output (a scoring rubric, keyword table, or step-by-step framework), the skills are working correctly.

<Note>
  Skills work immediately after installation using built-in ASO knowledge and frameworks. Connecting the Appeeky MCP Server (optional) upgrades every skill with live App Store data — real keyword volumes, competitor rankings, and chart positions.
</Note>

## Optional: Connect the Appeeky MCP Server

For real-time App Store data — live keyword volumes, competitor metadata, download estimates, and chart movements — connect the Appeeky MCP Server to Cursor.

Add the following to your MCP configuration (usually `.cursor/mcp.json` or your global Cursor MCP settings):

```json
{
  "mcpServers": {
    "appeeky": {
      "url": "https://mcp.appeeky.com/mcp",
      "headers": { "Authorization": "Bearer apk_your_key_here" }
    }
  }
}
```

Replace `apk_your_key_here` with your Appeeky API key. See the [Appeeky MCP guide](/guides/appeeky-mcp) for full setup instructions and how to obtain an API key.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Skills don't appear after installing">
    Start a **new** Agent chat — Cursor indexes skills at session start. Confirm `SKILL.md` files exist under `.cursor/skills/` (project), `~/.cursor/skills/` (global), or `.agents/skills/`. Run `ls .cursor/skills/` or `ls ~/.cursor/skills/` to verify.
  </Accordion>
  <Accordion title="Slash commands like /aso-audit aren't recognized">
    Skills installed via the manual method must be in the correct directory. Confirm that the `SKILL.md` files are present in `.cursor/skills/aso-audit/` (for project-level) or `~/.cursor/skills/aso-audit/` (for global). The router command is `/aso-router`, not `/aso-skill`.
  </Accordion>
  <Accordion title="The agent gives generic ASO advice instead of using the skill framework">
    Make sure you're invoking the skill by name (e.g., `/aso-audit`) rather than asking a free-form question. The slash command tells Cursor to load and follow the specific skill file. You can also use `/aso-router` as a universal router for any ASO request.
  </Accordion>
  <Accordion title="I want to update the skills">
    If you used the CLI, re-run the same install command to overwrite with the latest version. If you used clone-and-copy:

    ```bash
    cd aso-skills && git pull
    cp -r skills/* ../.cursor/skills/
    ```
  </Accordion>
</AccordionGroup>
