Install into Cursor, Claude Code, or any Agent Skills-compatible AI assistant and ask your agent to run audits, research keywords, analyze competitors, and generate optimized metadata — all backed by live App Store and Google Play data via the Appeeky MCP Server.

## Get up and running

<Steps>
  <Step title="Install skills into your AI agent">
    Add ASO Skills to Cursor via a Remote Rule, or run `npx skills add eronred/aso-skills` in Claude Code. See [Installation](/install/cursor) for full setup steps.
  </Step>
  <Step title="Connect the Appeeky MCP Server (optional but recommended)">
    Link the [Appeeky MCP Server](/guides/appeeky-mcp) so your agent can pull live App Store data — keyword volumes, competitor rankings, chart positions, and more.
  </Step>
  <Step title="Ask your agent anything about your app">
    Use the `/aso-skill` router or invoke skills directly. Try: _"Run an ASO audit for my app (id: 123456789)"_ or _"Find the best keywords for a meditation app."_
  </Step>
</Steps>
