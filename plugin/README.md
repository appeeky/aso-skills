# ASO Skills

40 App Store Optimization and app marketing skills for Claude: keyword research, metadata optimization, competitor analysis, market intelligence, screenshots, reviews, localization, user acquisition, monetization, App Store Connect metrics, and more.

## Install in Claude Code

```
/plugin marketplace add appeeky/aso-skills
/plugin install aso-skills@aso-skills
```

Skills are namespaced under the plugin, for example `/aso-skills:aso-audit`. Claude also loads them automatically when a request matches a skill. Start with `/aso-skills:aso-router` if you're not sure which skill you need.

## Live data (optional)

The skills work on their own. Connect the [Appeeky MCP server](https://docs.appeeky.com) for live App Store and Google Play data: keyword rankings, competitor metadata, reviews, and chart movements.
